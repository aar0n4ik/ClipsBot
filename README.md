# Автонарезка albert1million → TikTok, YouTube Shorts, Instagram Reels

Бот сам смотрит стримы Twitch, находит живые моменты, монтирует вертикальные клипы в фирменном шаблоне, делает свою версию под каждую площадку, выкладывает в выгодное время, учится на реальных просмотрах, следит за здоровьем аккаунтов и ведёт честный реестр выплат. Всё работает на бесплатном GitHub.

```
Twitch ─(10 мин)─► 1·Watch ─► 2·Process ─► версии под TikTok / Shorts / Reels ─► 3·Post (каждый час)
                                  │                                                   │
                                  └────► ветка data ◄── 4·Stats (каждый час) ◄─────────┘
                                         policy · decisions · health      5·Doctor (раз в сутки)
                                                   │
                                  дашборд на GitHub Pages (зашифрован паролем)
```

Только честные методы: никаких накруток, ботов, покупки просмотров и обхода правил площадок. Бан обнуляет всё, поэтому каждое правило ниже работает на долгую жизнь аккаунтов.

## v5: движок (октябрь 2026)

Дизайн и дашборд прежние — переделан двигатель.

**ИИ.** Нативный Gemini API вместо OpenAI-совместимой прослойки:
- **Ответы по JSON-схеме** (structured output): битый или неполный ответ ИИ невозможен физически.
- **Без `temperature` для Gemini 3+/4**: Google прямо требует убрать её при переходе на Gemini 3 (ниже 1.0 модель зацикливается и тупеет). v4 слал 0.1–0.3 во все запросы.
- **Уровни размышления** по задаче: режиссёр думает на `high`, отборщик и продюсер на `medium`, тексты и критик на `low`.
- **Облачная расшифровка речи** `gemini-3.5-transcribe` с таймкодами слов: все окна куска расшифровываются параллельно за секунды. Whisper на CPU остаётся запасным на каждое окно и сам не грузится, если облако справилось.
- **Лимиты по паре ключ × модель** с паузой из `RetryInfo` Google: исчерпанная суточная квота `gemini-4-argon` больше не выключает ключ для flash. Модель пропала или переименована — следующая по цепочке, в конце алиас `gemini-flash-latest`. Если модель не принимает какое-то поле API, оно отключается автоматически и запрос повторяется.
- **Второе мнение**: клип ровно на пороге режиссёр смотрит ещё раз независимо, итог — среднее вниз.
- Раз в 3 часа «доктор» проверяет каждый ключ и наличие моделей из настроек (дашборд → Настройки → Система → «ИИ»).

**Скорость.** Звук, чат и клипы зрителей качаются одновременно, кандидаты расшифровываются разом, пачки отборщика и просмотры режиссёра идут параллельно, исходники отобранных клипов скачиваются заранее, пока монтируется предыдущий. Свой загрузчик HLS тянет сегменты записи в 12 потоков (yt-dlp читает их по одному) и понимает fMP4/HEVC-записи Twitch, на которых v4 падал. Куски стрима — по **1 часу** вместо 2: клип с эфира выходит вдвое быстрее.

**Точность.** Исправлен сдвиг звука: обрезка «до входа» на склеенном TS сдвигала начало на ~0,2 с и теряла ~1 с в конце куска, из-за чего субтитры чуть отставали. Теперь рез точный до сэмпла (проверяется тестом). Один и тот же момент из перекрывающихся кусков больше не становится двумя клипами.

**Синхрон площадок.** Один клип — один релиз сразу на TikTok, Shorts и Reels, поэтому на всех площадках одинаковое число роликов.
- Если площадка отдыхает недолго (до 3 ч: лимит запросов и т. п.), новый релиз её ждёт.
- Если она надолго недоступна (бан на сутки, слетел вход), релиз идёт на остальные, а на ней этот клип не выходит вообще.
- Площадку, не принявшую ролик в момент релиза, бот дотягивает не позже чем через 2 ч. Позже — пропуск: «догонялок» через полдня нет.
- Починка не тратит лимит релизов в сутки.
- TikTok без аудита API получает черновик в ту же минуту, что и остальные площадки. Опубликуй его сразу, иначе время разойдётся.

**Ритм (решение по данным).** До **5 релизов в сутки**, на волне +1 (максимум 6), пауза **2 ч**, только клипы 7/10+.
- Buffer, 11,4 млн постов TikTok: чем больше постов, тем выше потолок (p90 растёт с 3,7k до 14,4k), а медиана не падает.
- Instagram: больше Reels в неделю — больше охват каждого и рост подписчиков.
- vidIQ, 10 млн каналов: рост YouTube продолжается до самой частой группы.
- Выше 5–6 в сутки данных нет, а риск флагов «спам» на молодом аккаунте и твоя ручная выкладка черновиков TikTok растут.
- Слабое не выходит никогда: качество важнее числа.
- Если в дашборде стояли старые значения по умолчанию (4 в сутки, 1,5 ч), бот заменит их сам и запишет это в журнал. Свои значения он не трогает.

**Монетизация TikTok.** Creator Rewards платит **только за ролики длиннее 1 минуты** (плюс 10k подписчиков и 100k просмотров за 30 дней). Ролики v4 были до 59 с, то есть не монетизировались бы никогда.
- В настройках есть переключатель «Ролики длиннее минуты». Включай его после 10k подписчиков.
- С ним истории и конфликты с развитием режутся на 63–90 с, а вырезка пауз не опускает их ниже минуты.
- Короткие сильные моменты остаются короткими: досмотр важнее.
- Учти: за просмотры из стран вне программы TikTok не платит. Основной доход — ставка стримера за просмотры на всех трёх площадках.

**Корректор субтитров и текстов.** Цель: субтитры, хуки, названия и подписи совпадают с тем, что реально сказано.
1. **Словарь стримера.** В `config.yaml` → `streamer.glossary` перечислены слова стрима, в `streamer.spelling` — пары «распознано → как правильно» (например «лутка → лудка»). Словарь подсказывает Whisper и корректору.
2. **Корректор по звуку.** Для каждого финалиста ИИ слушает фрагмент и сверяет его с пронумерованными словами распознавания. Исправляются только ошибки (сленг, имена, бренды, числа), речь стримера как есть не трогается. В опоре — звук, контекст и чат (зрители часто пишут сленг правильно). Все финалисты проверяются параллельно, это секунды.
3. **Самообучение.** Каждое исправление «было → стало» копится в `glossary.json`. Повторилось 2 раза — дальше применяется сразу и бесплатно ко всем новым расшифровкам (ещё до оценки ИИ) и к текстам. Ошибка, пойманная однажды, больше не повторяется.
- Исправления видны в карточке клипа.
- Субтитры YouTube не подходят: они появляются только после заливки, а сленг стрима их распознавание не знает так же.

**Надёжность.**
- **Без потери данных между воркфлоу.** Ветка `data` сливается трёхсторонне по ключам JSON. Раньше watch и process одновременно писали `status/system.json` и один молча затирал другого.
- **Без дублей при падении.** Перед загрузкой клип помечается «выкладываю». Если раннер умер посреди публикации, бот не перевыкладывает вслепую: stats найдёт ролик, а если его нет, в дашборде появится «Повторить».
- **Релиз во все площадки одновременно** (параллельно, а не по очереди). YouTube докачивает с места обрыва, а не с нуля.
- Статусы синхронизируются не чаще раза в 45 с. Ветка `data` раз в неделю сжимается в один коммит, так что репозиторий не пухнет месяцами.
- Расписание защищено от автоотключения GitHub после 60 дней тишины. Actions обновлены под Node 24 (Node 20 удалён с раннеров 23.09.2026), зависимости ставит `uv`. Каждый запуск пишет короткий отчёт во вкладку Summary.
- PBKDF2 — 600 000 итераций (рекомендация OWASP), дашборд совместим. Убрана подстановка кода OAuth прямо в shell-скрипт.

## Что внутри (v4: «мозг»)

### Отбор: четыре головы, которые спорят
1. **Разведчик** — Gemini слушает **весь** двухчасовой кусок стрима целиком (звук + таблица реакций чата по минутам) и отмечает моменты, которые пики чата и громкости пропускают: истории, тихие панчлайны.
2. **Отборщик** — по тексту Whisper оценивает каждого кандидата по жёсткой откалиброванной шкале 1–10 (что будет с роликом в ленте у незнакомого человека; «7 — досматривают, 8 — пересылают, 9 — раз в неделю»). Слабое отсекается до дорогих проверок.
3. **Режиссёр** — Gemini **смотрит видео** финалиста: есть ли момент на самом деле, нет ли лагов и зависаний (плюс техническая проверка `freezedetect` — зависшую запись бот отбрасывает, не тратя ИИ), где начать и закончить, какие паузы вырезать, правдивые заголовки и тексты под каждую площадку.
4. **Критик** — отдельная модель проверяет, что заголовок описывает то, что реально происходит. Не согласен — исправляет заголовок или зарезает клип.

Порог по умолчанию — **7/10 после просмотра видео**, максимум 3 клипа из часа стрима (обычно 0–2). Каждый отказ записывается с причиной: дашборд → Клипы → «Не взял».

### Монтаж
- Одно видео на все площадки (один рендер, один файл), разные только тексты.
- **Без «холодного открытия»**: ролик начинается с начала момента, никаких кусков развязки в начале.
- Паузы и молчание вырезаются: паузы длиннее 1,2 с по словам Whisper + куски, которые режиссёр отметил по видео; на стыках микрозатухание звука, без щелчков.
- **Камера как в оригинале**: одно положение на весь клип, никаких переездов. Сдвиг (один раз, статично) — только если включено в настройках и стример устойчиво за краем кадра.

### Выкладка: релиз сразу на все площадки
- Клип выходит на TikTok, Shorts и Reels **одновременно** (TikTok без аудита API — в черновики в ту же минуту, их нужно нажать «Опубликовать»).
- **ИИ-продюсер** каждый час видит всю картину (очередь, оценки, сколько слотов и активных часов осталось, как заходят последние ролики, идёт ли эфир) и решает: выкладывать сейчас или ждать, и что. Второй ИИ-критик проверяет решение. Жёсткие правила ИИ нарушить не может: ночь аудитории, пауза между релизами (90 мин), максимум в сутки (4), только клипы ≥ 7.
- Слабое не выкладывается никогда, «для количества» — тоже. Клип живёт 36 ч (9+ — 72 ч), дальше выбрасывается: на завтра не копим.
- **Волна**: если свежий ролик набирает в разы быстрее нормы, бот не молчит, а получает +1 релиз в сутки.
- **«Остывание» убрано.** Оно сравнивало новые ролики со старыми (майскими) и само резало частоту на здоровом канале. Площадки оценивают каждый ролик отдельно и не штрафуют за частоту при нормальном качестве; падение просмотров на маленьком канале — шум и качество, а не бан. Пауза площадке ставится только по прямым сигналам самой площадки (спам/лимит/блок).

### Почему так (данные)
- Buffer, 11,4 млн постов TikTok: чем чаще посты, тем выше шанс выстрела (p90 растёт с 3,7k до 14,4k), а медиана почти не меняется — объём помогает, только если ролики не слабые. Отсюда «качество ≥ 7, потом объём».
- Buffer, 100k+ аккаунтов: стабильность (каждую неделю) даёт до +450% вовлечённости — отсюда ежедневные релизы в похожие часы.
- YouTube (1 октября 2026) и Instagram (2026) режут охват перезаливов без своего вклада. Свой вклад здесь — отбор, монтаж с вырезанными паузами, правдивый хук, субтитры и фирменный шаблон; лучше всего работает, когда канал — самого стримера (YouTube прямо исключает контент самого автора).

### Дашборд
Вкладки: **Обзор** (лента дня с релизами и планом, деньги, площадки, конвейер нарезки с воронкой), **Клипы** (ждут, черновики TikTok, вышли, ошибки, «не взял» с причинами; «выложить сейчас», «не выкладывать»), **Аналитика** (оценка ИИ против реальных просмотров, темы, площадки, стиль заголовка, часы, таблица клипов), **Мозг** (как и почему продюсер решил, изменения поведения), **Управление** (ставка и порог вывода, реестр выплат с частичной оплатой, корректировками и правкой записей, пометки видео: дубликат / своё название / исключить), **Настройки** (кнопка «Стоп»: всё / только выкладка / только анализ; все параметры бота; ключ GitHub один раз для всех устройств; система).
Всё, что меняет данные, — только через окно подтверждения с тем, что именно изменится; остановка и смена ставки — ещё и словом-подтверждением.

### Деньги
Клип оплачивается один раз по площадке с лучшим результатом; рост после выплаты — доплата только за прирост; двойная оплата невозможна («оплачено до» по каждому клипу). Дубли склеиваются навсегда и считаются одним клипом. Ставка и порог — в дашборде (хранятся зашифрованно в `ledger.enc`), `MONEY_CONFIG` больше не нужен.

## Установка

### 1. Репозиторий и GitHub
1. **Публичный** репозиторий (например `clips`), залей все файлы из архива. В публичных репозиториях Actions бесплатны без лимита минут; секреты скрыты, данные дашборда и реестр зашифрованы.
2. Settings → Actions → General → Workflow permissions → **Read and write** → Save.
3. Settings → Pages → *Deploy from a branch* → `main`, папка `/docs`.

### 2. Twitch
dev.twitch.tv/console → Register Your Application (Redirect `http://localhost`, Confidential) → Client ID и Client Secret. Стример должен включить «Сохранять прошлые трансляции», и записи должны быть доступны всем.

### 3. TikTok
developers.tiktok.com → Connect an app → Login Kit + Content Posting API (включи Direct Post) → scopes `user.info.basic, video.upload, video.publish, video.list` → Redirect URI: `https://<ник>.github.io/clips/callback.html` → Terms и Privacy: `…/terms.html`, `…/privacy.html` (файл подтверждения домена положи в `docs/`). Пока нет аудита — режим `inbox` (черновики) или Sandbox.

### 4. YouTube Shorts — ручные шаги (10 минут)
1. console.cloud.google.com → новый проект → APIs & Services → **Enable APIs**: *YouTube Data API v3* и *YouTube Analytics API*.
2. **OAuth consent screen** → External → название, твой email, домен `<ник>.github.io`, ссылки на privacy и terms → scopes `youtube.upload`, `youtube.readonly`, `yt-analytics.readonly`.
3. **Важно:** Publishing status → **Publish app → In production**. В режиме Testing Google отзывает доступ каждые 7 дней. Проверку Google для своего канала проходить не нужно: при входе будет предупреждение «приложение не проверено» → *Advanced → Go to …*.
4. Credentials → Create OAuth client ID → *Web application* → Authorized redirect URI: `https://<ник>.github.io/clips/callback.html` → Client ID и Client Secret.
5. Загрузка через API — до 100 видео в сутки (отдельная квота), ролики выходят публично.

### 5. Instagram Reels — ручные шаги (15 минут)
1. Аккаунт Instagram — **профессиональный** (Настройки → Тип аккаунта → Бизнес или Автор).
2. developers.facebook.com → Create app → тип *Business* → добавь продукт **Instagram** → *API setup with Instagram login*.
3. Business login settings → Redirect URL: `https://<ник>.github.io/clips/callback.html` → скопируй **Instagram app ID** и **Instagram app secret**.
4. App roles → Roles → Add people → **Instagram Tester** → свой аккаунт. Затем в Instagram: Настройки → Приложения и сайты → Приглашения тестировщика → принять. Пока публикуешь только в свои аккаунты, проверка приложения Meta не нужна (режим разработки).
5. Лимит — 100 публикаций в сутки. Видео Instagram забирает по ссылке из GitHub Release (поэтому репозиторий публичный).

### 6. Секреты и переменные (Settings → Secrets and variables → Actions)
**Secrets:** `TWITCH_CLIENT_ID`, `TWITCH_CLIENT_SECRET`, `TIKTOK_CLIENT_KEY`, `TIKTOK_CLIENT_SECRET`, `YT_CLIENT_ID`, `YT_CLIENT_SECRET`, `IG_CLIENT_ID`, `IG_CLIENT_SECRET`, `DASHBOARD_PASSWORD`, `TOKEN_KEY` (случайная строка 40+ символов), ключи Gemini `GEMINI_API_KEY_*` (имена — в `config.yaml` → `llm.providers`, каждый нужно прописать в env воркфлоу process, post и doctor).

**Variables:** `OAUTH_REDIRECT_URI` = `https://<ник>.github.io/clips/callback.html`. Ставка и порог вывода задаются в дашборде.

`docs/app-config.js` → `tiktokClientKey`, `youtubeClientId`, `instagramClientId` (не секреты).

### 7. Подключить аккаунты
`https://<ник>.github.io/clips/connect.html` → выбери площадку → войти → скопируй код → Actions → **«0 · Connect account»** → Run workflow (платформа, `tt_main` / `yt_main` / `ig_main`, код). Код живёт несколько минут. Площадку можно подключить позже: бот начнёт делать под неё версии сам.

### 8. Запуск
Actions → **«1 · Watch Twitch»** → Run workflow. Дальше всё идёт по расписанию. В дашборде (Настройки) добавь ключ GitHub (Fine-grained token, только этот репозиторий, Contents и Actions: Read and write) — один раз, дальше он хранится в репозитории зашифрованным паролем дашборда.

## Что остаётся руками (5 минут в день, заметно влияет)
- TikTok в режиме `inbox`: открыть черновик → по желанию тихий трендовый звук → «Опубликовать». Готовые тексты копируются из карточки клипа.
- Первый комментарий (готовый, в карточке) и ответы на комментарии в первый час.
- В профилях — ссылка на twitch.tv/albert1million. Ник и аватар не менять часто.
- Ничего не удалять и не перезаливать.
- Подать на аудит TikTok Content Posting API, когда всё работает: после него `posting.tiktok.mode: direct`, и всё уходит само.

Гарантировать вирусность не может никто: алгоритмы закрыты. Бот закрывает всё, что от нас зависит, и с каждым днём точнее понимает, что заходит именно у вас.
