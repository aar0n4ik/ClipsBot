Privacy Policy

Last updated: October 17, 2026

This website is a private tool run by one individual. It publishes short clips of a Twitch streamer's broadcasts, made with the streamer's written permission, to TikTok, YouTube and Instagram accounts owned by the same individual.

What we access

  • Basic profile info from the connected TikTok, YouTube or Instagram account (display name, avatar, account ID) to show which account is connected.
  • Permission to upload videos to the connected account (as drafts or direct posts, as the account owner chooses).
  • The list of the connected account's own public videos and their view, like, comment and share counts, to show performance to the account owner.

How data is stored

Access tokens are stored encrypted (AES-256-GCM) in a repository controlled by the account owner. Statistics are stored encrypted and are visible only to people who hold the dashboard password. We do not sell, share or use data for advertising, and we do not access other users' data.

Retention and deletion

You can revoke access at any time: TikTok → Settings → Security → Manage app permissions; Google → myaccount.google.com/permissions; Instagram → Settings → Apps and websites. Revoking access stops all uploads and statistics collection; stored tokens become unusable. To request deletion of stored data, contact the operator below.

Contact

This app uses YouTube API Services; see the YouTube Terms of Service and Google Privacy Policy.

Questions about this policy: contact the operator of this site through the GitHub repository that hosts it.
